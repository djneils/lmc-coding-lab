        LMC instruction set
        
      
        
        
        
      
        
      
    
        
    
        
      
        
        
        MnemonicCodeWhat it doesExample
        
        
          
        Data movement
        
          
        LDA5xxLoad: copy the value stored at address xx into the accumulator.LDA NUM
        
          
        STA3xxStore: copy the accumulator’s value into address xx. STO also works.STA TOTAL
        
          
        Arithmetic
        
          
        ADD1xxAdd the value stored at address xx to the accumulator.ADD ONE
        
          
        SUB2xxSubtract the value stored at address xx from the accumulator.SUB ONE
        
          
        Input and output
        
          
        INP901Input: wait for a number to be typed in and put it in the accumulator.INP
        
          
        OUT902Output the value in the accumulator.OUT
        
          
        OTC922Output the accumulator as a character, for example 65 is output as A.OTC
        
          
        Branching
        
          
        BRA6xxBranch always: jump to address xx.BRA LOOP
        
          
        BRZ7xxBranch if zero: jump to address xx if the accumulator is 0.BRZ DONE
        
          
        BRP8xxBranch if positive: jump to address xx if the accumulator is 0 or more.BRP BIGGER
        
          
        Stopping and data
        
          
        HLT000Halt: stop the program. COB also works.HLT
        
          
        DAT–Data: not an instruction. Reserves a memory location, with an optional starting value. Usually labelled and placed after HLT. DAT with a label stores that label’s address.COUNT DAT 0
        
          
        Index register (Addressing modes option)
        
          
        LDX4xxLoad IX with a value: &n for a number, or an address.LDX &0
        
          
        INX903Add 1 to IX.INX
        
          
        DEX904Take 1 from IX.DEX
        
          
        TXA905Copy IX into the accumulator (so BRZ or BRP can test it).TXA
        
          
        TAX906Copy the accumulator into IX.TAX
        
                
      
        
    
        
    
        
      
        The addressing mode says how to use the operand: as the value itself, as an address, as the address of an address, or as a starting address plus the index register.
        
      
        
        In these examples
        address 1025
        address 257
        IX15
      
        
      
        
        
        
          
        Immediate &
        
          
        The operand is the value. No memory is read.
        
          
        LDA &10→ACC = 10
        
          
        Use for constants, without needing a DAT. Fast, but only 0–99 fits in an LMC instruction.
        
        
        
        
        
          
        Direct (symbolic)
        
          
        The operand is the address of the value. A label is just a name for that address.
        
          
        LDA 10→10: 25→ACC = 25
        
          
        The everyday mode: variables stored at fixed addresses.
        
        
        
        
        
          
        Indirect #
        
          
        The operand is the address of a location that holds another address (a pointer).
        
          
        LDA #10→10: 25→25: 7→ACC = 7
        
          
        The pointer can change while the program runs, so one instruction can reach many locations. Real CPUs also use it to reach addresses too big to fit in the operand.
        
        
        
        
        
          
        Indexed ,X
        
          
        The operand is a starting address. The index register is added to it.
        
          
        LDA 10,X→10 + IX 15 = 25→25: 7→ACC = 7
        
          
        Ideal for lists and arrays: point at the start, then step along with INX.
        
        
        
      
        
      
        LMC instructions only have room for two digits, so this app stores each instruction’s mode alongside it. A real CPU uses extra bits in the instruction to say which mode to use.
        
    
        
    
        In a code, xx is the two-digit address the instruction uses. Labels such as LOOP or TOTAL stand for an address, so the assembler works out xx for you.
