        One instruction per line: an optional label, the mnemonic, then an address or label.         Symbol table
        
      
    
        
    
        When the program is assembled, each label is replaced by the address it stands for. This is the table the assembler builds to do that.
        
    
        
  
        

        


        
  
        
    
        
      
        LMC instruction set
        
      
    
        
    
        
      
        
        
        MnemonicCodeWhat it doesExample
        
        
          
        Data movement
        
          
        LDA5xxLoad: copy the value stored at address xx into the accumulator.LDA NUM
        
          
        STA3xxStore: copy the accumulator’s value into address xx. STO also works.STA TOTAL
        
          
        Arithmetic
        
          
        ADD1xxAdd the value stored at address xx to the accumulator.ADD ONE
        
          
        SUB2xxSubtract the value stored at address xx from the accumulator.SUB ONE
        
          
        Input and output
        
          
        INP901Input: wait for a number to be typed in and put it in the accumulator.INP
        
          
        OUT902Output the value in the accumulator.OUT
        
          
        OTC922Output the accumulator as a character, for example 65 is output as A.OTC
        
          
        Branching
        
          
        BRA6xxBranch always: jump to address xx.BRA LOOP
        
          
        BRZ7xxBranch if zero: jump to address xx if the accumulator is 0.BRZ DONE
        
          
        BRP8xxBranch if positive: jump to address xx if the accumulator is 0 or more.BRP BIGGER
        
          
        Stopping and data
        
          
        HLT000Halt: stop the program. COB also works.HLT
        
          
        DAT–Data: not an instruction. Reserves a memory location, with an optional starting value. Usually labelled and placed after HLT.COUNT DAT 0
        
                
      
        
    
        
    
        In a code, xx is the two-digit address the instruction uses. Labels such as LOOP or TOTAL stand for an address, so the assembler works out xx for you.
